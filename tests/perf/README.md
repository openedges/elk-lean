# tests/perf

Synthetic benchmark results (`sh scripts/run_perf_benchmark.sh 20 3 tests/perf`): the 26 scenarios of
elk-rs `perf_benchmark.rs` (`rust_api` engine: JSON string in, JSON string out) for

- `rust_api.csv`, `rust_native.csv`: the oracle `.reference/elk-rs-target/release/perf_benchmark`
  (elk-rs `eb586b6d`, release, system allocator),
- `lean_api.csv`: `elk bench` (`Elk.Api.layoutJson`, the path of the NAPI/WASM bindings),
- `baseline_lean_api.csv`: the lean_api run the 5% regression gate compares against (refreshed after
  each accepted optimisation step),
- `report.md`: per-scenario times, lean/rust ratio and the gate result (`scripts/compare_perf.py`).

Only `baseline_lean_api.csv` and `report.md` are tracked; the other CSVs are regenerated by every run.
Numbers are machine specific (see `report.md`); compare runs on the same machine only.
